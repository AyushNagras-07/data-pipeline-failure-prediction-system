# Sequential Models (`src/models/`)

## 1. What This Folder Is
This subpackage will contain the neural-network architectures, training routines, and inference logic for our sequential failure-prediction models.

## 2. Why This Folder Exists
As required by the **Advanced Neural Network Architectures (ANNA - Track 2: Sequential Models / Time-Series)** specification, we are conducting a comparative evaluation across sequential architectures. Isolating model definitions and training logic here ensures clean experimentation, modular architecture swapping, and standardized checkpoint management.

## 3. What Will Eventually Be Stored Here
This directory will contain:
- **`rnn_model.py`**: A standard Recurrent Neural Network (Vanilla RNN) baseline designed for sequential classification.
- **`lstm_model.py`**: A Long Short-Term Memory network utilizing memory cells and input/forget/output gates to model longer temporal dependencies across execution runs.
- **`gru_model.py`**: A Gated Recurrent Unit network utilizing reset and update gates to provide a lightweight alternative to LSTM.
- **`train.py`**: Unified training loop handling loss computation (Binary Cross-Entropy), backpropagation, optimization (e.g., Adam), early stopping, and checkpoint saving.
- **`predict.py`**: Inference pipeline accepting an input sequence of length $W$ and returning:
  - `Failure Probability` (e.g., 0.82)
  - `Success Probability` (e.g., 0.18)
  - `Risk Level` (`LOW`, `MEDIUM`, `HIGH`)

## 4. How It Connects to the Overall Project
- **Input:** Ingests 3D sequence tensors generated by `src/features/`.
- **Output:** Produces trained model artifacts, loss curves, and predictions delivered to `src/evaluation/` for metric assessment and comparative study.

## 5. What We Are NOT Doing Yet
- We are **not** implementing neural network layers, training scripts, or weights at this stage.
- Model construction and training will commence in **Phase 6**.
